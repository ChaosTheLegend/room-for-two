## 💤 Room for Two
Adds the ability for multiple players to sleep in a bed.
## Features
- Allows multiple players to sleep in a single bed.
- A player can also sleep in a bed with a villager.
- Provides an alternative sleeping position when sleeping with someone else.
- Adds varying camera angles depending on the perspective. (WIP)
## ⚙️ Modpack Usage
Room for Two is free to be used in any custom modpacks as long as credit is provided. However, compatibility with existing mods has not been tested for, so use at your own risk.
## 🔨 Version Support
Room For Two will get updates for as many versions as possible, prioritising newest versions.
